## Identity

- **Project name:** Leaf · Read & Listen
- **Purpose:** An installable personal library for reading book pages while listening to synchronized narration.
- **Primary users:** Readers who want a calm combined reading and listening experience.
- **Repository:** dn-lx/book-reader
- **Owner/team:** dn-lx

## Architecture

- **Frontend/runtime:** Vanilla JavaScript modules and Vite; PDF.js is loaded on demand. Installable PWA.
- **Backend/runtime:** Static application; no application server. Private Sites access gate is enforced by hosting.
- **Database/storage:** IndexedDB for user-imported PDF/audio books; localStorage for device-local preferences, progress and bookmarks. Cache Storage for explicit offline book downloads.
- **Hosting/deployment:** Private ChatGPT Sites deployment; public GitHub repository contains code only, not private book text or narration.
- **Authentication:** Owner-only access enforced by the private hosting platform; no credentials in frontend code.
- **Key architectural boundaries:** Built-in book assets are private deployment inputs. Imported books and reading state stay on the device; no cross-device sync or analytics.
